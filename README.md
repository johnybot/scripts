Here are some Mesen Lua scripts I use to help me work on my NES games



BgUpdate.lua:
Highlights background updates in the game window
![bgUpdate](https://github.com/user-attachments/assets/d6b59bae-d4ac-4f7b-acd8-a4bfda33706c)

SpriteChart.lua:
Charts sprite usage per scanline
![spriteChart](https://github.com/user-attachments/assets/d8e0cc8f-1c18-4129-b7d5-dde653d13453)

vblank.lua:
Charts vblank utilization
![vblank](https://github.com/user-attachments/assets/641916de-4022-47c1-ba33-c4fe14dd4a0e)

irqCallback.lua
Draws a horizontal line on the scanline an IRQ occurs
![irqCallback](https://github.com/user-attachments/assets/68ca4c83-bc75-4064-9f11-667a9783fbab)

safeArea.lua
Draws the Safe Area overlaid on top of the screen
![safeArea](https://github.com/user-attachments/assets/1c9bf750-4142-4d9f-993d-5f39ed3aa923)

grid.lua
Draws a 16px x 16px grid over the game
![grid](https://github.com/user-attachments/assets/b39468ad-c90f-4646-a2fc-e80468340c26)
